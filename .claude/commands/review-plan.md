Read CLAUDE.md. Record that a site's biosecurity management plan was reviewed.

Run `npm run farm -- review-plan <site> [--on=YYYY-MM-DD] --actor=`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Only record a review that actually happened. Ask for the date.
