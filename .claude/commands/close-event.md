Read CLAUDE.md. Close a mortality event with its cause and what was done. Refused until it has been reported.

Run `npm run farm -- close-event <event> --cause= --note= [--on=YYYY-MM-DD] --actor=`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Ask for the lab result or the cause the vet gave, and what changed on the farm.
