Read CLAUDE.md. Feed used at each site over the last 365 days against the yearly cap in its consent or licence.

Run `npm run farm -- feed-cap`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Over 100% is a consent breach: say so plainly. Over 90%, say how many tonnes are left and roughly how many days at the 30-day rate.
