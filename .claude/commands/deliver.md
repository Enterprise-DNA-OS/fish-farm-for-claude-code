Read CLAUDE.md. Record a feed delivery with its lot and docket number.

Run `npm run farm -- deliver --feed= --kg= [--lot=] [--docket=] [--on=YYYY-MM-DD] --actor=`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Lot numbers matter for traceability: ask for them if the docket is to hand.
