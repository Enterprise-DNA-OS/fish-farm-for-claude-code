Read CLAUDE.md. Draft the feed return for a site's consent: tonnes of feed by month against the yearly limit.

Run `npm run farm -- feed-return <site> [--months=12]`. Flags use `--name=value`; quote values with spaces. Add `--json` for structured results. Use the operator's actual values, drop optional brackets, and never run a literal placeholder.

Writes a draft to drafts/. The consent sets the period and form; check it before lodging.
